# docs/ 문서 안내

이 폴더는 게임 기획·서사·작업 계획을 담는다. 하위 폴더의 책임은 엄격히 분리한다.

- `concept/` — **게임 설정**. 능력치·상태값·이벤트 카드·전투 규칙 등 *엔진이 굴러가게 만드는 모든 시스템 정의*. 표기 SSOT(`dictionary.md`)도 여기에 둔다.
- `story/` — **스토리 설정**. 세계관·문파·등장인물·아이템·지역 서사 등 *콘텐츠 카탈로그*. concept 가 "어떻게 굴러가는가"라면 story 는 "무엇으로 채우는가".
- `plans/` — **작업 계획 메모리**. `/plan-memory` 스킬이 채우는 slug 별 작업 폴더 (`spec.md`/`context.md`/`checklist.md`). 세션 간 작업 재개용.

## 새 문서 추가 시

먼저 어느 폴더 책임인지 판단한다.

| 질문 | concept | story |
|---|---|---|
| 능력치/스탯/판정 규칙인가? | ✔ | |
| 게임 엔진 코드가 직접 참조할 데이터인가? | ✔ | |
| 세계관·인물·문파·아이템 설정인가? | | ✔ |
| 서사·대사·분위기 묘사인가? | | ✔ |

경계가 애매하면 `concept/` 가 우선이다 (시스템이 콘텐츠보다 먼저 굳어야 한다).
