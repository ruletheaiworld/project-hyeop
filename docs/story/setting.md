# setting — 강호 설정집

문파·등장인물·아이템 카탈로그를 한 문서에서 관리한다. 이벤트 카드(`eventEditor`)와
게임 엔진이 참조하는 **세계관 SSOT**.

> 한글 표기는 `../concept/dictionary.md` 가 SSOT. 새 명칭을 도입할 때 사전과 합의되지 않은
> 변형 표기를 쓰지 않는다.

각 카탈로그가 무거워지면 별도 md 로 분리한다 (예: `setting-sects.md`).
지금 단계에선 한 문서 한 눈에 보는 게 우선.

---

## 1. 문파 (sects)

| 필드 | 설명 |
|---|---|
| `id` | 영문 snake_case (예: `huasan_pa`) |
| 이름 | 한글 표기 (예: `화산파`) |
| 진영 (faction) | `정파` / `사파` / `마교` / `중립` |
| 거점 지역 | `청운현 / 외곽` 같은 표기 |
| 무공 계열 | 예: 검법 / 권법 / 암기 / 마공 |
| 수장 | 인물 `id` 참조 (없으면 비움) |
| 묘사 | 한두 문장 분위기 |
| 메모 | 자유 |

## 3. 아이템 (items)

`system.md` §3 의 `Item` 타입을 따른다. 카탈로그 규모는 `direction.md` 4-1 의
"10개 이하" 약속을 지킨다.

| 필드 | 설명 |
|---|---|
| `id` | 영문 snake_case (예: `sword_iron`) |
| 이름 | 한글 표기 (예: `철검`) |
| 타입 | `weapon` / `consumable` / `manual` / `misc` |
| 효과 | 한 줄 설명 (보유 효과·이벤트 메모 등) |
| 획득 경로 | 어느 이벤트에서 얻는가 (이벤트 `id` 참조) |
| 메모 | 자유 |
