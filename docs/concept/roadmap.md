# 무협 텍스트 어드벤처 개발 로드맵

먼저 해야 할 건 **스토리 쓰기**가 아니라, "게임의 반복 구조"를 정하는 거야.

서울 2033을 참고한다면 핵심은 이거임.

> 짧은 선택 → 능력/아이템/상태에 따라 결과 분기 → 생존/성장/이벤트 해금 → 다음 선택

무협 버전이면 이렇게 바꾸면 됨.

> 강호를 떠돌며 사건을 만남 → 선택함 → 무공/내공/명성/문파/인연에 따라 결과가 달라짐 → 성장하거나 다침 → 더 큰 사건에 휘말림

---

## 첫 단계: 게임의 한 줄 정의 잡기

제일 먼저 이걸 정해야 함.

```text
플레이어는 어떤 사람이고,
무협 세계에서 무엇을 하며,
매번 어떤 선택을 반복하는 게임인가?
```

예시:

```text
플레이어는 몰락한 문파의 마지막 제자로,
강호를 떠돌며 무공을 익히고 인연을 만들며,
문파의 멸문 뒤에 숨겨진 진실을 추적한다.
```

또는 더 서울 2033스럽게 가면:

```text
플레이어는 이름 없는 낭인으로,
강호 곳곳에서 사건을 해결하거나 외면하며,
살아남고 강해져 최종적으로 천하제일인이 되거나 비참하게 죽는다.
```

이 한 줄이 없으면 나중에 이벤트가 중구난방으로 늘어남.

---

## 두 번째: 핵심 능력치 정하기

처음부터 복잡하게 만들면 망함. 최소한으로 시작하는 게 좋음.

추천 능력치:

```text
체력
내공
무공
지혜
명성
악명
은전
```

무협 느낌을 더 살리려면 상태값도 필요함.

```text
부상
중독
현상수배
문파 소속
사부 있음
원한 관계
기연 획득
```

서울 2033식으로 보면 능력치는 "선택지를 열거나 닫는 열쇠"임.

예시:

```text
[무공 3 이상] 정면으로 맞선다
[지혜 2 이상] 수상한 낌새를 눈치챈다
[명성 5 이상] 사람들의 도움을 받는다
[악명 5 이상] 협박한다
[은전 10 필요] 의원에게 치료받는다
```

## 세 번째: 이벤트 구조 만들기

이 게임의 핵심 단위는 "이벤트 카드"임.

처음에는 이런 형식으로 만들면 됨.

```text
이벤트명:
객잔의 수상한 검객

지역:
청운현 / 객잔

발생 조건:
없음

상황:
밤늦게 객잔에 들어서자, 피 묻은 검을 든 사내가 구석에 앉아 있다.

선택지:
1. 모른 척한다.
   - 조건: 없음
   - 결과: 체력 +1

2. 말을 건다.
   - 조건: 없음
   - 결과: 전투 발생

3. 점소이에게 사정을 묻는다.
   - 조건: 은자 2냥 이상
   - 결과: 은자 -2, 단서 획득

4. 검객의 기세를 살핀다.
   - 조건: 무예 3 이상
   - 결과: 성공 시 명성 +1 / 실패 시 부상

후속 이벤트:
전투_수상한_검객

메모:
초반 전투 튜토리얼용 이벤트
```

처음부터 세계관 대서사 쓰지 말고, 이런 이벤트를 20개 정도 만드는 게 먼저임.

## 네 번째: MVP 범위 정하기

처음 버전은 작게 만들어야 함.

```text
플레이 시간: 5~10분
이벤트 수: 20~30개
엔딩 수: 3~5개
능력치: 5~7개
아이템: 10개 이하
전투: 아주 단순하게
저장 기능: 나중에
```

첫 목표는 "재밌는가?" 확인이지, 거대한 무협 오픈월드 만드는 게 아님.

MVP 구조는 이렇게 가면 됨.

```text
캐릭터 생성
↓
랜덤 이벤트 진행
↓
능력치/아이템/상태 변화
↓
특정 조건 달성 시 엔딩
```

## 다섯 번째: 세계관은 크게 말고 '지역'부터 만들기

무협 세계 전체를 먼저 짜면 너무 커짐.

처음에는 지역 3개만 만들면 됨.

```text
청운현
초반 마을. 객잔, 의원, 표국, 뒷골목 이벤트 발생.

흑풍산
산적, 기연, 동굴, 은거고수 이벤트 발생.

낙양성
문파, 비무대회, 정보상, 권력 암투 이벤트 발생.
```

지역마다 이벤트 성격을 다르게 하면 게임이 살아남.

```text
청운현 = 생존/초반 선택
흑풍산 = 위험/기연/전투
낙양성 = 정치/명성/문파/돈
```

---

## 여섯 번째: 엔딩 먼저 정하기

텍스트 어드벤처는 엔딩을 먼저 잡아야 이벤트 방향이 생김.

초기 엔딩 예시:

```text
천하제일인 엔딩
무공과 내공이 높고 최종 비무에서 승리.

마교 타락 엔딩
악명과 살업이 높고 마공을 익힘.

은거기인 엔딩
명성은 낮지만 지혜와 내공이 높음.

객사 엔딩
체력이 0이 되거나 중독 방치.

문파 재건 엔딩
특정 인연, 은전, 명성, 무공 조건 달성.
```

이렇게 엔딩이 있어야 이벤트마다 "이게 어디로 연결되는가?"가 생김.

## 일곱 번째: 개발 로드맵

```text
1주차
게임 한 줄 정의, 능력치, 상태값, 엔딩 3개 정리

2주차
이벤트 데이터 구조 설계
이벤트 20개 작성
선택지 조건/결과 포맷 만들기

3주차
텍스트 기반 프로토타입 구현
선택지 출력, 능력치 변화, 랜덤 이벤트 진행

4주차
전투/부상/아이템 최소 구현
엔딩 조건 연결

5주차
반복 플레이 테스트
재미없는 이벤트 삭제
선택지 보상 조정

6주차
UI 정리
저장 기능
로그/도감/업적 추가 검토
```

## 제일 먼저 만들 것

바로 이 순서로 하면 됨.

```text
게임 한 줄 정의
↓
능력치 5~7개
↓
엔딩 3개
↓
이벤트 카드 10개
↓
JSON 구조
↓
콘솔 프로토타입
↓
이벤트 30개로 확장
```

지금 당장 할 일은 **스토리 전체를 쓰는 게 아니라 이벤트 카드 10개를 만드는 것**임.

첫 목표는 이거야.

```text
"무협 서울 2033 느낌이 난다."
"선택이 능력치와 연결된다."
"죽거나 강해지는 흐름이 있다."
```

이 3개만 느껴지면 1차 성공임.
