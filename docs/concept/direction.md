# direction — 게임 방향성, 취향, 수정 의견

## 용어 사전

문서 전반에서 쓰이는 표기 약속.

| 표기 | 의미 |
|---|---|
| `{n}d{m}` | `m`면체 주사위를 `n`개 굴린다. 예: `2d6` = 6면체 주사위 2개. |

## 1. 한 줄 정의 (확정)

로드맵 첫 번째 단계인 "게임의 한 줄 정의"는 아래 텍스트로 간다.

> 당신은 이제 막 강호에 발을 들인 이름 없는 강호인이다.
>
> 정해진 길은 없다.
> 누군가를 도와 명성을 얻을 수도 있고,
> 약한 자를 약탈해 악명을 쌓을 수도 있다.
> 무예를 갈고닦아 천하를 넘볼 수도 있으며,
> 은자를 모아 오늘 하루를 버틸 수도 있다.
>
> 강호는 당신에게 아무것도 약속하지 않는다.
> 살아남는 것, 강해지는 것, 어떤 이름으로 기억되는 것.
> 그 모든 것은 당신의 선택에 달려 있다.

## 2. 핵심 능력치와 상태값

### 2-1. 핵심 능력치

모든 능력치는 이벤트를 통해 변동이 일어날 수 있으며, 능력치에 따라 고를 수 있는
선택지가 달라지거나 발생하는 이벤트가 다르다.

**능력치 목록**: 체력, 내공, 무예, 학식, 명성, 도덕, 은자

> 표기·동의어·영문 키 통일 규칙은 `dictionary.md` 참조 (SSOT). 본 표는 게임 디자인
> 설명 용도이며, 표기가 충돌하면 사전이 이긴다.

| 능력치 | 설명 |
|---|---|
| 체력 (hp) | 이벤트에서 깎이거나 회복하거나 가능. |
| 내공 | 단전에 모인 기운. 일정 수치 이상에서 기연·깨달음을 얻거나, 무예 판정 시 내공을 실어 위력을 키울 수 있다. |
| 무예 | 각종 기술 습득을 통해 얻는 능력치. 추후 도검 / 권법 / 암기 등으로 세분화 필요하지만 우선 하나로 감. |
| 학식 | (설명 보강 예정) |
| 명성 | 강호 내에서의 명성. |
| 도덕 | 주인공의 도덕성. 높으면 선함, 낮으면 악함. |
| 은자 | 돈. |

### 2-2. 상태값

상태값은 플레이어의 현재 상황과 과거 행적을 기록하는 **비정량적 데이터**이다.
부상·중독 같은 일시적 상태부터 문파 소속·사부·원한 관계·기연 획득 같은
장기적 플래그까지 포함한다.

능력치와 마찬가지로 이벤트와 선택지에 영향을 주지만, **숫자 성장보다는 조건
충족 여부와 서사 분기를 표현**하는 데 사용된다.

### 2-3. 능력치 vs 상태값

능력치와 상태값은 유사하다. 차이점은 다음과 같다.

- **능력치**는 플레이어의 역량을 **숫자로 나타낸 값**이다.
- **상태값**은 플레이어의 상황·관계·이력·특수 조건을 **태그로 나타낸 값**이다.

둘 다 이벤트와 선택지에 영향을 주지만,

- **능력치**는 *정도를 비교*하는 데 쓰이고 (예: 무예 ≥ 3),
- **상태값**은 *조건 여부를 판단*하는 데 쓰인다 (예: 문파 소속 == 화산파).

## 3. 이벤트 카드

### 3-1. 두 가지 조건 구분

- **이벤트 발생 조건** = 이 사건이 나타날 수 있는가?
- **선택지 조건** = 이 사건 안에서 이 선택지를 고를 수 있는가?

### 3-2. 발생 조건

발생 조건은 특정 이벤트가 등장하기 위해 필요한 **능력치, 상태값, 지역, 진행도,
이전 선택 이력**을 의미한다.
발생 조건을 만족하지 않으면 해당 이벤트는 **랜덤 이벤트 후보에서 제외**된다.

### 3-3. 이벤트 카드 포맷 (예시)

```text
id:
cheongun_inn_swordsman

이벤트명:
객잔의 수상한 검객

이벤트 타입:
일반이벤트

활성 상태:
on

발생 가중치:
6

지역:
청운현 / 객잔

발생 조건:
없음

상황:
밤늦게 객잔에 들어서자, 피 묻은 검을 든 사내가 구석에 앉아 있다.

선택지:
1. 모른 척한다.
   - 조건: 없음
   - 결과: 체력 +1

2. 말을 건다.
   - 조건: 없음
   - 결과: 전투 발생

3. 점소이에게 사정을 묻는다.
   - 조건: 은자 2냥 이상
   - 결과: 은자 -2, 단서 획득

4. 검객의 기세를 살핀다.
   - 조건: 무예 3 이상
   - 결과: 성공 시 명성 +1 / 실패 시 부상

후속 이벤트:
전투_수상한_검객

메모:
초반 전투 튜토리얼용 이벤트
```

### 3-4. 새 필드 설명

| 필드 | 설명 |
|---|---|
| **id** | 이벤트 고유 식별자. `후속 이벤트` 지정, `seenEvents` 중복 방지, `choiceHistory` 기록 등 게임 엔진의 모든 카드 참조가 이 값을 쓴다. 상세 규칙은 3-4-1. |
| **이벤트 타입** | 이벤트의 분류. 예: `프롤로그`, `일반이벤트`, `전투이벤트`, `엔딩이벤트`. |
| **활성 상태** | `on` / `off`. `off`인 카드는 후보 풀에서 제외되어 등장하지 않는다. |
| **발생 가중치** | `0`~`10`. 가중 랜덤에서의 비중. 높을수록 자주 등장. **`0`은 랜덤 등장에서 완전히 제외**되며, 오직 다른 카드의 `후속 이벤트`로 지정됐을 때만 발생한다 (전투·결말·후속 전용 분기 카드 표기용). |

#### 3-4-1. id 생성·명명 규칙

- **유일성**: 카드 간 id 중복 금지. 충돌하면 `후속 이벤트` / `seenEvents` 참조가 깨진다.
- **수동 명명 (권장)**: ASCII `snake_case` 슬러그.
  - 권장 형식: `지역_장소_주제` (예: `cheongun_inn_swordsman`, `cheongun_road_old_man`)
  - 타입이 명확한 카드는 `타입_주제`도 가능 (예: `prologue_first_step`, `ending_obit`)
- **자동 생성 (eventEditor)**: 카드 신규 생성·복제 시, 그리고 id 칸을 비운 채 포커스를 빠지면 다음 형식으로 자동 채움.
  ```
  ev_<base36-milliseconds>_<5자랜덤>
  예: ev_lqz9x4_3kp7m
  ```
  접두 `ev_`로 자동 생성 id임을 식별 가능.
- **권장 흐름**: 자동 id로 가볍게 시작 → 카드 내용이 굳어지면 의미 있는 슬러그로 교체.

### 3-5. 이벤트 선택 우선순위

다음 이벤트는 아래 순서로 결정한다.

1. **1순위 — 후속 이벤트**
   직전에 고른 선택지에 `후속 이벤트`가 지정되어 있으면, 무조건 그 이벤트가
   다음에 발생한다. (가중치·랜덤 무시)
2. **2순위 — 가중 랜덤**
   후속 이벤트가 없으면, 현재 시점에 등장 가능한 이벤트
   (`발생 조건` 충족 + `활성 상태` = `on` + `발생 가중치` ≥ `1`)들의
   `발생 가중치`를 합해 비율대로 가중 랜덤 선택한다.
   `발생 가중치 = 0`인 카드는 이 풀에서 제외된다 (후속 이벤트로만 도달 가능).

## 4. MVP 범위와 진행 흐름

### 4-1. MVP 범위

| 항목 | 목표치 |
|---|---|
| 플레이 시간 | 5 ~ 10분 |
| 이벤트 수 | 20 ~ 30개 |
| 엔딩 수 | 5개 |
| 능력치 | 5 ~ 7개 |
| 아이템 | 10개 이하 |
| 전투 | `2d6 + 무예 + 상태값` |
| 저장 기능 | 나중에 |

### 4-2. 진행 흐름

```text
캐릭터 생성
      ↓
랜덤 이벤트 진행
      ↓
능력치 / 아이템 / 상태 변화
      ↓
특정 조건 달성 시 엔딩
```

## 5. 지역

3개 지역으로 간다. 이름도 로드맵 표기 그대로 사용한다.

| 지역 | 단계 | 키워드 | 주요 이벤트 |
|---|---|---|---|
| **청운현** | 초반 마을 | 생존 / 초반 선택 | 객잔, 의원, 표국, 뒷골목 |
| **흑풍산** | 위험 지대 | 위험 / 기연 / 전투 | 산적, 기연, 동굴, 은거고수 |
| **낙양성** | 후반 도시 | 정치 / 명성 / 문파 / 돈 | 문파, 비무대회, 정보상, 권력 암투 |

## 6. 엔딩

엔딩 5종으로 간다.

| 엔딩 | 조건 |
|---|---|
| **천하제일인 엔딩** | 무예와 내공이 높고 최종 비무에서 승리. |
| **마교 타락 엔딩** | 악명과 살업이 높고 마공을 익힘. |
| **은거기인 엔딩** | 명성은 낮지만 학식과 내공이 높음. |
| **객사 엔딩** | 체력이 0이 되거나 중독 방치. |
| **문파 재건 엔딩** | 특정 인연, 은자, 명성, 무예 조건 달성. |
