## 일반 이벤트

### 청운현 가도의 노인

```text
id:
cheongun_road_old_man

이벤트명:
청운현 가도의 노인

이벤트 타입:
일반이벤트

활성 상태:
on

발생 가중치:
8

지역:
청운현 / 가도

발생 조건:
없음

상황:
청운현으로 향하는 흙길 위, 한 노인이 망가진 수레 옆에 주저앉아 있다.
바퀴 한쪽이 빠져 짐 보따리가 길바닥에 쏟아져 있고, 노인은 지친 눈으로
지나가는 당신을 바라본다.

선택지:
1. 수레를 함께 들어 길가로 옮겨준다.
   - 조건: 없음
   - 결과: 체력 -1, 도덕 +1, 명성 +1

2. 모른 척 지나간다.
   - 조건: 없음
   - 결과: 변화 없음

3. 노인의 짐을 빼앗는다.
   - 조건: 없음
   - 결과: 은자 +3, 도덕 -2, 명성 -1, 상태값: 원한 관계(노인) 획득

4. 수레 구조를 살펴 직접 고쳐준다.
   - 조건: 학식 2 이상
   - 결과: 도덕 +1, 명성 +2, 상태값: 인연(노인) 획득

후속 이벤트:
없음

메모:
- 도덕 / 명성 축이 어떻게 움직이는지 체감시키는 입문용 이벤트.
- 4번은 학식 게이트 선택지의 첫 노출. 조건 미충족 시 잠금 상태로 표시.
- 3번 선택 시 "원한 관계(노인)" 상태값을 통해 후속 사건이 분기될 여지를 남겨둔다.
```
