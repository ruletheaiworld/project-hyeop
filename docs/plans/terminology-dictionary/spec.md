# spec — terminology-dictionary

## 목표

`docs/concept/dictionary.md` 를 만들어 **게임 내 표기의 SSOT(Single Source of Truth)** 로
삼는다. 같은 개념을 가리키는 여러 표현이 문서·카드·코드에 흩어진 상태를 끝내고, 정식 표기
1개를 못박는다.

## 범위

- 포함 (1차):
  - 핵심 능력치 7종의 정식 표기 통일: **체력 / 내공 / 무예 / 학식 / 명성 / 도덕 / 은자**
  - 각 능력치의 영문 키 (`system.md` 와 동기화: `hp` / `qi` / `martial` / `knowledge` / `renown` / `morality` / `money`)
  - 각 능력치별 **사용 금지 표기 목록** (예: 무공 / 무력 → 무예)
  - 향후 확장 자리(상태값·지역·이벤트 타입·아이템 카테고리) 헤더만 박아 두기

- 제외 (1차):
  - 상태값(부상·중독·문파 등) 용어 정리 — 2차 작업
  - 지역명·이벤트 타입명 정리 — 3차 작업
  - 기존 문서·카드의 표기 일괄 치환 — 별도 작업으로 분리

## 완료 조건 (Definition of Done)

- [ ] `docs/concept/dictionary.md` 가 존재
- [ ] 7개 능력치 표가 다음 4컬럼으로 정리됨: **정식 표기 / 영문 키 / 사용 금지(대체될 표기) / 한 줄 설명**
- [ ] 영문 키가 `docs/concept/system.md` 의 능력치 스키마와 정확히 일치
- [ ] `direction.md` 의 능력치 설명과 본 사전이 충돌하는 곳이 없거나, 사전 쪽이 더 정확하다고 표시됨
- [ ] 사전이 SSOT 임을 명시하는 한 줄이 `concept/claude.md` 또는 `direction.md` 에 추가됨

## 인터페이스 / 데이터 형식

문서만 만드는 작업. 데이터 형식 정의는 별도 작업.

표 컬럼:

| 컬럼 | 예시 |
|---|---|
| 정식 표기 | `무예` |
| 영문 키 | `martial` |
| 사용 금지 | `무공`, `무력` |
| 한 줄 설명 | 도검·권법·암기 등 외공 숙련도 합계. 내공과 합쳐 전투 판정에 사용. |

## 의존성

- 외부 라이브러리·서비스·CLI: 없음
- 사전 작업으로 끝나야 하는 항목: 없음 (`system.md` / `direction.md` 가 이미 존재하면 충분)

## 비고

- 사전은 **표기 통일** 만 책임진다. "그래서 무예가 정확히 뭘 하는가" 같은 **규칙 정의**는
  여전히 `direction.md` / `system.md` 가 담당.
- 1차 범위만 끝나면 단독으로 가치가 있음. 상태값·지역 정리는 별도 작업으로 큐잉.
- 영문 키와 한글 표기가 어긋나면 코드(eventEditor, 추후 엔진)에서 충돌이 가장 크게
  드러나므로 영문 키는 절대 손대지 않고 한글 표기만 통일한다.
